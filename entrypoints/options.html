Добро пожаловать в LexiSync

  • Исправление ошибок и улучшение стиля
  • Перевод, эмодзи и пользовательские команды
  • Быстрые команды и локальная история

Добавьте API-ключ Mistral

Ключ нужен для AI-команд и хранится только в локальном хранилище расширения.

Открыть Mistral Studio ↗
  1. Войдите в аккаунт Mistral или создайте новый
  2. В меню слева найдите раздел API Keys
  3. Нажмите Create new key и сразу скопируйте ключ

Выполните первую команду

LexiSync работает прямо с текстом на открытой странице.

  1. 1Выделите текст на любом сайте
  2. 2Нажмите кнопку LexiSync рядом с выделением
  3. 3Выберите команду, затем замените или скопируйте результат

Быстрые команды

Выделите текст на странице или используйте горячие клавиши.

  • Alt+R — исправить ошибки
  • Alt+Y — переписать текст
  • Alt+T — добавить эмодзи
  • Alt+S — распознать текст на экране

Приватность под вашим контролем

Текст отправляется в Mistral только для выполнения выбранной AI-команды.

  • Контекст страницы по умолчанию отключён
  • API-ключ и история хранятся локально
  • Историю и данные можно очистить в настройках
