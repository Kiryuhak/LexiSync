Где взять API-ключи?

✦ Mistral AI

  1. Перейдите на console.mistral.ai.
  2. В меню слева найдите раздел API Keys.
  3. Нажмите Create new key и скопируйте его.

⚡ Groq (Qwen 3.6 27B)

  1. Перейдите на console.groq.com/keys.
  2. В меню слева найдите раздел API Keys.
  3. Нажмите Create API Key и скопируйте его.

Добро пожаловать в LexiSync

Расширение помогает исправлять, переводить и улучшать текст прямо на странице.

  • Исправление ошибок и улучшение стиля
  • Перевод, эмодзи и пользовательские команды
  • Быстрые команды и локальная история

Добавьте API-ключ Mistral

Ключ нужен для AI-команд и хранится только в локальном хранилище расширения.

Открыть Mistral Studio ↗
  1. Войдите в аккаунт Mistral или создайте новый
  2. В меню слева найдите раздел API Keys
  3. Нажмите Create new key и сразу скопируйте ключ

⚡ Groq · Qwen 3.6 27B · Preview

Добавьте API-ключ Groq

Ключ нужен для быстрой модели Qwen 3.6 27B и автоматического переключения при лимитах.

Открыть Groq Console ↗
  1. Войдите в аккаунт Groq или создайте новый
  2. В меню слева найдите раздел API Keys
  3. Нажмите Create API Key и скопируйте его

Выполните первую команду

LexiSync работает прямо с текстом на открытой странице.

  1. 1Выделите текст на любом сайте
  2. 2Нажмите кнопку LexiSync рядом с выделением
  3. 3Выберите команду, затем замените или скопируйте результат

Быстрые команды и клавиши

Используйте горячие клавиши или плавающую панель LexiSync:

  • Alt+R Исправление ошибок и опечаток
  • Alt+Y Переписать / Другими словами
  • Alt+T Добавить выразительные эмодзи
  • Alt+S Распознать текст на экране (OCR)
  • 0 мс Тихое исправление раскладки и текста
  • Tab Принятие локальных подсказок на лету

Приватность под вашим контролем

Текст отправляется выбранному AI-провайдеру только для выполнения команды. При автоматическом переключении резервный сервис получает текст лишь после временной ошибки основного.

  • Контекст страницы по умолчанию отключён
  • API-ключ и история хранятся локально
  • Историю и данные можно очистить в настройках
