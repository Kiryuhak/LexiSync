# Карточка LexiSync 5.6.8 для магазинов

Материалы предназначены для ручного переноса в Chrome Web Store и Firefox Add-ons. Перед публикацией необходимо сверить карточку с финальным архивом версии 5.6.8.

## Название

Корректор грамматики и орфографии — LexiSync

## Краткое описание

Умный помощник с орфографией Яндекс.Спеллера и AI-проверкой через Mistral и Cloudflare Workers AI.

## Полное описание

LexiSync помогает работать с текстом прямо на веб-странице: исправляет орфографию, грамматику и пунктуацию, переписывает и переводит фрагменты, меняет раскладку, улучшает стиль, добавляет эмодзи и распознаёт текст на выбранной области экрана.

Орфографию проверяет официальный облачный API Яндекс.Спеллера. Для грамматики, пунктуации и контекста расширение поддерживает Mistral AI и Cloudflare Workers AI: можно выбрать основной AI-сервис и включить однократное резервное переключение. Для AI-запросов используются собственные ключи пользователя.

Ключевые возможности:

- работа с выделенным текстом через компактное меню, контекстное меню и горячие клавиши;
- проверка русской и смешанной русско-английской орфографии через Яндекс.Спеллер по явной команде пользователя;
- три режима проверки: гибридный (Спеллер → AI), только Яндекс.Спеллер и только AI;
- надёжная защита выделения (snapshot) и проверка полей ввода/DOM перед заменой;
- корректор с защитой ссылок, email, чисел, структуры строк и технических идентификаторов;
- Mistral AI и Cloudflare Workers AI с выбором активной модели;
- OCR выбранной области страницы через Mistral AI;
- локальная история, словарь, глоссарий, сниппеты и статистика использования;
- отключённая по умолчанию передача контекста страницы и автоматическая проверка при вводе;
- локальная маскировка распространённых персональных данных;
- зашифрованный экспорт и необязательная резервная копия в закрытой папке приложения Google Drive.

LexiSync не содержит телеметрии и серверов разработчика для обработки текста. При проверке орфографии текст отправляется по HTTPS Яндекс.Спеллеру; AI-запросы — непосредственно выбранному AI-провайдеру. Запросы запускаются после действия пользователя, чувствительные поля исключаются. Резервная копия шифруется локально с помощью AES-256-GCM, а мастер-пароль не сохраняется и не отправляется Google.

[Проверка правописания: Яндекс.Спеллер](https://api.yandex.ru/speller/)

## Примечания к выпуску 5.6.8

- Local Proofreader заменён официальным API Яндекс.Спеллера: быстрая проверка орфографии русского и английского текста с точным позиционированием исправлений.
- Добавлен гибкий выбор режимов: гибридный (Спеллер → AI), только Яндекс.Спеллер и только AI.
- В панели результата добавлена кнопка «Проверить через AI», позволяющая отправить проверенный текст на глубокий стилистический и грамматический анализ без потери найденных исправлений.
- Исправлена обработка числовых диапазонов: типографическая замена `5-10` на `5–10` не блокирует корректный ответ AI, но изменение самих значений по-прежнему запрещено.
- Атрибуция Яндекс.Спеллера размещена отдельной читаемой строкой и не обрезается в компактной панели.
- Устранена потеря состояния кулдауна Mistral при перезапуске Service Worker MV3 за счёт хранения в session storage с надёжным fallback в local storage.
- Оптимизирована работа резервного провайдера Cloudflare Workers AI в режиме анализа стиля.

## Обоснование разрешений

- `storage`: локальные настройки, история, кэш и несекретная синхронизация предпочтений.
- `activeTab`: временная работа с активной вкладкой после действия пользователя.
- `scripting`: запуск упакованного интерфейса LexiSync на разрешённой вкладке.
- `contextMenus`: команды для выделенного текста и изображений.
- `identity`: безопасный вход Google по действию пользователя без ручного копирования токенов.
- `https://api.mistral.ai/*`: текстовые AI-запросы и OCR по явной команде пользователя.
- `https://api.cloudflare.com/*`: текстовые запросы к Cloudflare Workers AI по явной команде пользователя.
- `https://speller.yandex.net/*`: проверка орфографии через Яндекс.Спеллер по явной команде пользователя.
- `https://www.googleapis.com/*`: необязательная загрузка и восстановление зашифрованной резервной копии Google Drive.
- необязательный доступ к HTTP/HTTPS-сайтам: постоянная работа только на сайтах, которые пользователь разрешил отдельно.
