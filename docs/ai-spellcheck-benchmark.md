# Benchmark русской проверки текста в Cloudflare Workers AI

Дата прогона: 11 сентября 2026 года (01:43, Asia/Yekaterinburg).

## Методика

- Выполнено 84 реальных REST-запроса к Cloudflare Workers AI: 28 одинаковых синтетических примеров для каждой из трёх моделей, доступных в LexiSync.
- Во всех запросах использованы одинаковая консервативная инструкция корректора, `temperature: 0`, `max_tokens: 512` и непотоковый ответ.
- Для `@cf/zai-org/glm-4.7-flash` отключено рассуждение через `chat_template_kwargs.enable_thinking: false`: отдельная runtime-диагностика доказала, что без этого модель периодически расходует все 512 токенов на `reasoning_content` и возвращает пустой `message.content` с `finish_reason: length`.
- Тестовые данные не содержат пользовательский текст или секреты. Account ID и API Token оставались внутри изолированной копии профиля Firefox и не выводились в отчёт.
- «Точное совпадение» означает побайтовое совпадение результата с ожидаемым текстом. Это строгая метрика: отсутствие финальной точки также считается несовпадением.

Вывод: текущая `GLM-4.7-Flash` с отключённым reasoning — лучший из проверенных вариантов для русского spellcheck. При равном с Qwen числе точных совпадений она не вернула ни одного пустого ответа, потребовала примерно в 31 раз меньше output tokens и сохранила URL, email, числа, даты, пути и идентификаторы. Qwen три раза исчерпала лимит без ответа. Llama быстрее, но чаще пропускает ошибки и один раз исказила смысл фразы.

## Существенные отклонения

- GLM в примере 2 исправила обе опечатки и поставила запятую, но не добавила финальную точку; в примерах 8 и 25 заменила `ё` на `е`; в примерах 12, 13, 16 и 18 пропустила часть пунктуационных или грамматических ошибок. При этом модель не внесла опасных смысловых изменений и сохранила все технические данные.
- Qwen три раза вернула пустой ответ после расходования 512 completion tokens. В примере 19 модель изменила обратные слеши технического пути, что нарушает правило сохранения идентификаторов.
- Llama в примере 2 заменила исходную фразу на смыслово неверную, в примере 21 переформатировала дату, а в примере 23 перефразировала предложение. Для консервативного корректора это неприемлемо.

## Решение для LexiSync

1. Сохранить `@cf/zai-org/glm-4.7-flash` моделью Cloudflare по умолчанию.
2. Для режима `spellcheck` использовать непотоковый REST-ответ: интерфейс всё равно показывает исправление только после полной проверки качества.
3. Для GLM в `spellcheck` обязательно передавать `chat_template_kwargs: { enable_thinking: false }`. Это устраняет доказанную причину пустого ответа без увеличения таймаута и сокращает расход с сотен completion tokens примерно до 6–18.
4. Сохранить потоковый режим для генеративных операций, где пользователь действительно видит части длинного ответа.
5. Не переключать spellcheck на Qwen или Llama по умолчанию по результатам этого прогона.
