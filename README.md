## ✨ Что нового в 5.5.0

- **⚡ Интеграция Groq API и Qwen 3.6 27B:** Добавлена высокоскоростная модель `qwen/qwen3.6-27b` через Groq API для сверхбыстрой обработки текста и генерации ответов.
- **🔄 Автоматический Fallback:** Интеллектуальное бесшовное переключение между Mistral и Groq при исчерпании квот (429 Too Many Requests), сбоях сети или недоступности серверов (5xx).
- **🎛️ Выбор основного AI-провайдера:** В настройках можно выбрать предпочитаемый сервис (_Автоматически_, _Mistral AI_, _Groq — Qwen 3.6_) и управлять включением fallback.
- **🛡️ Защищённое хранилище секретов:** API-ключи Groq сохраняются в изолированной IndexedDB (`lexisync-secrets`), исключены из облачной синхронизации и экспорта настроек.
- **👁️ Удобное управление ключами:** Добавлены переключатели видимости пароля (иконки глаза), валидация ключей в настройках и поддержка Groq в мастере быстрого старта (онбординге).

## 🚀 Основные возможности

- **📝 Исправление ошибок (Alt+R):** Автоматическая проверка орфографии и пунктуации с понятной diff-подсветкой.
- **🎭 Смена стиля (Alt+Y):** Переписывание выделенного текста в заданном тоне (деловой, дружеский, лаконичный и т.д.).
- **⚡ Тихое исправление на месте:** Коррекция опечаток и раскладки клавиатуры за 0 мс прямо в поле ввода.
- **😊 Подбор эмодзи (Alt+T):** Нейросеть анализирует контекст и предлагает выразительные эмодзи.
- **🌐 Умный переводчик:** Контекстный перевод на 10+ языков с автоопределением исходного языка.
- **⌨️ Смена раскладки:** Быстрое исправление текста, набранного не в той раскладке (например, `ghbdtn` -> `привет`).
- **📸 Mistral OCR (Alt+S):** Извлечение текста из невыделяемых областей экрана, презентаций и скриншотов.
- **✨ Персональные подсказки:** Локальное дописывание слов на лету и принятие подсказок по нажатию клавиши `Tab`.
- **🛡️ Локальная маскировка PII:** Включённая по умолчанию защита email, телефонов, карт, IP-адресов и токенов до отправки запроса в Mistral AI с восстановлением значений в готовом тексте.
- **📚 Галерея и свои AI-команды:** Создание собственных действий и библиотека готовых шаблонов.
- **⚡ Текстовые макросы:** Локальное раскрытие собственных сокращений в обычных полях ввода без запроса к AI.
- **🧰 Локальные инструменты:** Смена регистра, типографика и очистка лишних пробелов без передачи текста внешним сервисам.
- **🕒 История запросов на IndexedDB:** Локальное хранение до 500 записей с поиском, фильтрами, избранным и экспортом в JSON, CSV или Markdown.
- **📋 Мультиформатный буфер:** Копирование как форматированного текста для Word / Docs, так и чистого Plain Text.
- **🎨 7 современных стилей интерфейса:** Liquid Glass, MagicOS, Aurora Glass, Material Design 3, Flutter Clean, Vision Aurora и Silk Obsidian со светлой и тёмной темами.
- **🔒 Полная приватность:** Обработка только по действию пользователя, нулевая внешняя телеметрия, поддержка приватных окон и посайтовых исключений.

## 🛠 Технологии и архитектура

- **Язык:** TypeScript 7 в строгом режиме с отдельной проверкой совместимости TypeScript 6
- **Сборка:** WXT 0.21 + Vite
- **API:** WebExtensions Manifest V3, Mistral AI API
- **Хранилище:** IndexedDB для истории запросов, chrome.storage.local с автоочисткой TTL для кэша и настроек
- **Интерфейс:** Чистый Vanilla DOM (без runtime-накладных расходов), Shadow DOM изоляция, кэширование SVG-шаблонов (`cloneNode`), CSS-переменные

## 🎯 Качество и тестирование

Проект покрыт автоматическими модульными, интеграционными и браузерными тестами, которые дополняются ручной проверкой интерфейса. Особое внимание уделено следующим аспектам:

- **Устойчивость API:** Временные ошибки обрабатываются ограниченным числом внутренних попыток, после чего пользователь сам решает, повторять ли запрос.
- **Изоляция UI:** Всплывающий интерфейс размещается в Shadow DOM и не конфликтует со стилями веб-страниц.
- **Граничные случаи при работе с DOM:** Безопасная вставка и замена текста в различных типах узлов (`<input>`, `<textarea>`, `contenteditable`), включая сохранение фокуса и позиции каретки.
- **Безопасность данных:** Строгая типизация данных при записи и чтении из асинхронного `chrome.storage.local`.
- **Приватное хранение:** История и кэш отключены в приватных окнах и могут быть запрещены для выбранных доменов.
- **Автоматическая проверка:** GitHub Actions на Node.js 24 проверяет форматирование, ESLint, TypeScript, зависимости готового расширения, требования Manifest V3 и целостность ZIP, запускает модульные тесты с покрытием, функциональные сценарии Chrome и проверку запуска Firefox.
- **Доступность и адаптивность:** Автоматический axe-аудит страниц расширения и визуальные контракты для ширины 320, 625 и 1000 пикселей.
- **Редакторы и фреймы:** E2E-проверки замены в `contenteditable` и работы горячих клавиш внутри iframe.

## ⚙️ Разработка и сборка

```bash
npm ci                   # воспроизводимая установка из package-lock.json
npm run dev              # Chrome с автоматическим обновлением
npm run dev:firefox      # Firefox с автоматическим обновлением
npm run build            # финальные сборки обоих браузеров
npm run zip              # архивы для Chrome Web Store и Firefox AMO
npm run xpi:firefox      # XPI для временной локальной установки Firefox
npm run clean:artifacts  # удалить старые архивы релизов, сохранив текущую версию
npm run typecheck        # строгая проверка TypeScript
npm run lint             # статический анализ ESLint
npm run format:check     # проверка форматирования Prettier
npm run test:unit        # модульные тесты Vitest без запуска браузера
npm run test:coverage    # модульные тесты с порогами покрытия
npm run test:e2e         # функциональные тесты Chrome
npm run test:firefox     # временная установка сборки в Firefox через web-ext
npm run screenshots:store # обновить русские скриншоты для README и витрины
npm run verify:manifests # проверка разрешений финальных манифестов
npm run verify:release   # финальные ZIP, MV3, целостность и Firefox Add-ons
npm run test:all         # полный набор автоматических проверок
```

Для разработки рекомендуется Node.js 24; минимальная поддерживаемая версия — 22.15. Готовые релизные сборки создаются в `.output/release/chrome-mv3` и `.output/release/firefox-mv3`. Команды `npm run zip:chrome` и `npm run zip:firefox` создают отдельные архивы для магазинов.

## 📦 Установка

- **Chrome Web Store:** установите расширение из [официального магазина Chrome Web Store](https://chromewebstore.google.com/detail/%D0%BA%D0%BE%D1%80%D1%80%D0%B5%D0%BA%D1%82%D0%BE%D1%80-%D0%B3%D1%80%D0%B0%D0%BC%D0%BC%D0%B0%D1%82%D0%B8%D0%BA%D0%B8-%D0%B8-%D0%BE%D1%80/iacebnbpapcgjlplkeapekjeoljfdpgl).
- **Firefox Add-ons:** установите LexiSync напрямую из [официального каталога Firefox Add-ons (AMO)](https://addons.mozilla.org/ru/firefox/addon/65facfa619b74330bdfa/).
- **Chrome для локальной разработки:** выполните `npm run build:chrome`, перейдите на страницу `chrome://extensions/`, активируйте _Режим разработчика_, нажмите _Загрузить распакованное расширение_ и укажите папку `.output/release/chrome-mv3`.
- **Firefox для локальной разработки:** выполните `npm run build:firefox` (или `npm run xpi:firefox`), откройте `about:debugging#/runtime/this-firefox`, нажмите _Загрузить временное дополнение..._ и выберите файл `.output/release/firefox-mv3/manifest.json` (либо созданный `.xpi`).

## 🔑 Начало работы

1. Получите API-ключ:
    - **Mistral AI:** зарегистрируйтесь на [console.mistral.ai](https://console.mistral.ai/) и создайте API-ключ.
    - **Groq (Qwen 3.6 27B):** зарегистрируйтесь на [console.groq.com/keys](https://console.groq.com/keys) и получите бесплатный ключ с высоким лимитом скорости.
2. Откройте страницу настроек LexiSync (через иконку расширения на панели браузера).
3. Вставьте ключи в поля «Mistral API Key» и/или «Groq API Key», нажмите **Проверить** и выберите основной AI-провайдер (_Автоматически_, _Mistral AI_ или _Groq_).
4. Убедитесь, что включен чекбокс «Автоматический fallback», чтобы запросы продолжали выполняться даже при исчерпании лимитов одного из сервисов.
5. Выделите любой текст на странице и вызовите LexiSync через всплывающую панель или горячие клавиши (например, `Alt+R` для проверки орфографии).
