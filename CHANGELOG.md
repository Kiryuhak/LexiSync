# Changelog

## [5.2.0] - 2026-08-09

### Добавлено

- Номер версии в шапке настроек стал доступной кнопкой и открывает компактную историю всех выпусков LexiSync.
- История обновлений содержит понятные пользовательские описания на русском и английском языках, поиск по версии и изменению, а также отметку текущего выпуска.
- Страница настроек получила цветную шапку, спокойный анимированный фон и отдельное понятное описание для каждой вкладки.
- У основных параметров появились короткие пояснения о назначении API-ключа, стиля текста и поисковой системы.

### Исправлено

- Выключение фоновой автопроверки, добавление сайта в исключения и уход со страницы теперь отменяют ожидающий таймер и активный запрос до обращения к API.
- Завершение старого запроса больше не сбрасывает ссылку на более новую автопроверку.
- Синхронизация настроек больше не повторяет запись между `storage.local` и `storage.sync`, когда Firefox сообщает событие без фактического изменения значения.
- Повтор запроса и уточнение результата больше не оставляют пустое модальное окно: предыдущее дерево Preact корректно размонтируется перед новым рендером.
- Добавлен регрессионный E2E-сценарий для последовательных действий «Повторить» и «Короче».
- «Повторить» теперь всегда обходит локальный кеш и получает новый вариант от API.
- Firefox smoke-тест корректно завершает дерево процессов `web-ext` и браузера.
- Персональная подсказка больше не теряет активное поле из-за устаревшего таймера при быстром переключении между полями.

### Улучшено

- Версия в исходном коде, блокировке зависимостей и релизном теге теперь проверяется до запуска длительных тестов.
- Установка Firefox XPI предварительно проверяет все production-архивы, манифесты и хеш скопированного файла.
- Проверка инструментов сборки блокирует новые high/critical-уязвимости; разрешены только две отслеживаемые проблемы `image-size` в цепочке `web-ext`.
- Обновлены безопасные patch-версии Playwright, ESLint, типов Chrome/Node и TypeScript ESLint; добавлена проверка SVG-ассетов.
- В проверку релизных архивов добавлен лимит размера стартовых скриптов, а команда `clean:artifacts` безопасно удаляет только архивы прежних версий.

## [4.1.0] - 2026-07-28

### Исправлено и оптимизировано

- Пакетное разбиение больше не теряет начало длинных абзацев и не разрывает UTF-16 символы, CRLF и мягкие границы предложений.
- Пакетные задания сохраняются в IndexedDB: обработку можно приостановить, продолжить после повторного открытия панели и повторить только неудачный файл.
- Устаревшие запросы проверки при вводе отменяются, а черновик боковой панели сохраняется с задержкой вместо записи после каждого символа.
- Лимиты запросов и токенов получили атомарное резервирование, поэтому параллельные варианты не могут обойти бюджет.
- `sidepanel.ts` разделён на контроллер пакетных заданий, клиент запросов, модель команд, историю и мост страницы.

### Безопасность и интерфейс

- API-ключ перенесён из доступного content scripts `storage.local` в приватную IndexedDB расширения с автоматической миграцией.
- В автопроверке можно отклонять отдельные зелёные исправления и отключать функцию для текущего сайта.
- Добавлена отмена последней замены, сделанной из рабочей панели.
- Диагностический отчёт не включает API-ключ, историю, тексты и адреса исключённых сайтов.

### Инструменты и выпуск

- Версия повышена до 4.1.0, WXT обновлён до 0.21.2.
- TypeScript 7.0.2 используется для нативной проверки типов параллельно с TypeScript 6 для совместимости ESLint.
- Покрытие расширено на бюджет, пакетные задания, разбиение текста, цепочки и настройки темы; повышены минимальные пороги.
- Добавлен workflow создания GitHub Release и опциональной отправки архивов в Chrome Web Store и Firefox Add-ons.

## [3.0.0] - 2026-07-28

### Добавлено

- Полная релизная проверка Manifest V3 для Chrome и Firefox: точные разрешения, service worker, декларация данных Firefox, CSP и запрет удалённого исполняемого кода.
- Проверка целостности ZIP-архивов: безопасные пути, уникальные имена, границы данных, размеры и CRC32 каждого файла.
- Тесты длинных текстов, формата `Retry-After`, изоляции кэша и ограничений локального хранилища.

### Изменено

- Инструменты обновлены до актуального совместимого стека: WXT 0.21, TypeScript 6, ESLint 10, Vitest 4, Playwright 1.62 и Prettier 3.9.
- CI переведён на Node.js 24 и актуальные закреплённые по SHA версии GitHub Actions.
- Включена строгая npm-политика install-скриптов с точечным разрешением проверенных версий.
- Настройки сохраняют только изменённые поля и не перезаписывают параллельные изменения popup.
- Повторные запросы Mistral корректно учитывают `Retry-After`, освобождают сетевой поток и не смешивают ответы при быстрой отмене или новом запуске.
- Миграции читают только ключи настроек, не загружая историю, кэш и API-ключ.

### Оптимизировано и защищено

- Сравнение исправлений ограничено по памяти и времени: очень длинный текст больше не создаёт квадратичную LCS-матрицу.
- Кэш принимает только SHA-256-ключи LexiSync и ограниченные по размеру ответы; повреждённый индекс не может удалить посторонние настройки.
- История и статистика проверяют режимы, даты, идентификаторы и размеры данных перед записью.
- Усилены правила TypeScript, ESLint и пороги покрытия модульными тестами.

## [2.18.0] - 2026-07-28

### Добавлено

- Компактный результат теперь используется по умолчанию для новых установок.

- Режимы отображения результата «Авто», «Компактно» и «Подробно» с живым предпросмотром в настройках.
- Интерактивные зелёные исправления в компактной панели: просмотр «было → стало» и возврат исходного фрагмента.
- Проверка входящих AI- и OCR-запросов в background, нормализация адресов исключённых сайтов и доступные статусы операций.
- Автоматическая проверка паритета русской и английской локализаций, ссылок `data-i18n` и ключей `t()`.

### Оптимизировано

- Потоковый ответ обновляет интерфейс пакетами, а оборванный SSE-поток больше не считается успешным.
- Адаптивная модель сохраняет изученные слова пакетно и использует независимую очередь хранилища.
- Проверка версии настроек больше не читает всю историю, кэш и языковую модель при каждом запуске service worker.
- OCR и адаптивные подсказки вынесены в отдельные загружаемые скрипты; основной content bundle уменьшен.
- Панель результата разделена на модули управления запросом, исправлениями, действиями и доступностью.

### Надёжность

- Настройки сайта изменяются атомарно с блокировкой интерфейса и полным откатом при ошибке.
- Копирование и сохранение показывают успех только после завершения операции; настройки предупреждают о несохранённых изменениях.
- CI разделяет production- и E2E-сборки, проверяет содержимое финальных ZIP и запускает аудит всех зависимостей.
- Повышены пороги покрытия; добавлены тесты миграций, пакетных записей, валидации, режимов результата и клавиатурного управления.
